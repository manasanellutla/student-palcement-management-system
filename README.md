
# Student Placement Management System

## 1. Project Description
The Student Placement Management System is a web-based application developed using HTML, CSS and JavaScript. It helps colleges manage student profiles, company registrations, eligibility checking, interview scheduling and placement reports.

## 2. Objectives
- To maintain student profile details.
- To register companies and job roles.
- To check student eligibility based on CGPA.
- To schedule company interviews.
- To generate placement reports.

## 3. Technologies Used
- HTML – To create the structure of the website.
- CSS – To design and style the website.
- JavaScript – To implement functionality and validation.

## 5. Modules

### 1. Student Profile Management
- Enter student name.
- Enter roll number.
- Enter email address.
- Enter CGPA.
- Add student skills.
- Save student profile.

### 2. Company Registration
- Enter company name.
- Enter job role.
- Enter minimum CGPA.
- Register the company.
- Display registered companies.

### 3. Eligibility Checking
- Check student CGPA.
- Compare student CGPA with company requirements.
- Display eligibility results.

### 4. Interview Scheduling
- Enter company name.
- Select interview date.
- Select interview time.
- Schedule interviews.
- Display scheduled interviews.

### 5. Placement Reports
- Display total students.
- Display registered companies.
- Display scheduled interviews.
- Refresh placement reports.

## 6. How to Run the Project

1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Make sure all project files are available.
4. Open the index.html file.
5. Right-click and select Open with Live Server.
6. The Student Placement Management System will open in your browser.

## 7. Expected Output

The application displays five main sections:

1. Student Profile Management
2. Company Registration
3. Student Eligibility Checking
4. Interview Scheduling
5. Placement Reports

Users can enter details, register companies, check eligibility, schedule interviews and view placement statistics.
